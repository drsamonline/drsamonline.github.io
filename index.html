    How this page is built

    One HTML file. No web fonts, no CDN, no framework, no tracking. The project list is baked into the page, so it paints before anything else can happen — and it still works opened from a USB stick with the Wi-Fi switched off.

    It is also alive: when a connection exists, the page quietly re-reads the repository data and any project you have published since the last build appears on its own, no redeploy needed.

    Press offline in the bar to cut the network inside this tab and watch it carry on.
